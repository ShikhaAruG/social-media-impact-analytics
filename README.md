# Social Media Impact on Student Wellbeing & Academic Performance

## Project Overview
This project analyzes the relationship between daily social media usage, sleep hygiene, perceived stress, and academic performance (GPA) across 4,500 student records. It utilizes a Business Intelligence framework (KPIs -> Trends -> Drivers -> Actions) alongside machine learning models (Linear Regression and Random Forest) to predict student GPA outcomes and categorize academic risk.

## Dataset Link
- **Dataset:** [Kaggle - Social Media Impact on Life](https://www.kaggle.com/datasets/harishyadav0506/impact-of-social-media-on-life) 

## Key Findings
- **Average Screen Time:** 5.30 hours/day
- **Late-Night Usage Exposure:** 58.8% of students
- **Primary Driver:** Daily usage hours shows a strong negative correlation with GPA ($r = -0.70$) and a positive correlation with stress ($r = 0.75$).

## Project Structure
- `Social_Media_impact_on_life.ipynb`: Combined Jupyter Notebook containing data cleaning, exploratory data analysis, visualizations, and machine learning models.
